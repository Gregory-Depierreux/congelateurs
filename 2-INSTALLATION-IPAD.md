# 2. Installer l'application sur l'iPad

À faire une fois, avec une connexion Internet.

1. Sur l'iPad, ouvrir **Safari** et saisir l'adresse obtenue à l'étape de déploiement (`https://VOTRE-NOM.github.io/congelateurs/`).
2. Attendre l'affichage de l'accueil « Mes congélateurs ».
3. Toucher le bouton **Partager** (carré avec une flèche vers le haut).
4. Choisir **Sur l'écran d'accueil**. Si la ligne n'apparaît pas, faire défiler la liste ou toucher « Modifier les actions ».
5. Vérifier le nom « Congélateurs », puis toucher **Ajouter**.
6. Fermer Safari. Ouvrir l'application depuis sa nouvelle icône (flocon blanc sur fond bleu). Elle s'ouvre en plein écran, sans barre d'adresse.
7. Test hors connexion : activer le mode Avion, fermer l'application, la rouvrir. Elle doit s'afficher normalement.

## Trois règles à respecter

- **Toujours ouvrir l'application depuis son icône**, jamais depuis Safari. L'application installée et Safari ont chacun leur propre espace de données : ce qui est saisi dans l'un n'apparaît pas dans l'autre. De plus, Safari peut effacer les données d'un site resté sans visite ; l'application installée n'est pas soumise à cette règle.
- **Ne pas supprimer l'icône** de l'écran d'accueil sans avoir fait une sauvegarde : considérez que cela efface les données.
- **Ne pas utiliser la navigation privée** pour l'installation.

Le bandeau bleu « Pour conserver vos données durablement… » s'affiche tant que l'application est ouverte dans un navigateur. Il disparaît dans l'application installée : c'est le signe que tout est en ordre.

## Autres appareils

L'application fonctionne aussi sur iPhone (même procédure), sur Android et sur ordinateur. Chaque appareil possède son propre stock : il n'y a pas de synchronisation. L'iPad est l'appareil de référence. Pour copier les données vers un autre appareil, utiliser une sauvegarde puis une restauration.

## Ce qui n'a pas pu être vérifié avant la livraison

L'application a été testée sous Chrome sur ordinateur, pas sur un iPad réel. À la première installation, merci de vérifier les points 6 et 7 ci-dessus, ainsi que l'enregistrement d'une sauvegarde dans Fichiers (guide 3).
